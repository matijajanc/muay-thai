N · Analog dial anatomy

1 2 3 4 5
  1. 1Wedge = time left. A full circle is the current phase (3:00 round, 2:00 rest, 10 s lead-in), so every phase starts full.
  2. 2Hand sweeps clockwise from 12 as the phase runs.
  3. 3Warning arc on the rim marks the last 10 s. When the hand reaches it, the wedge turns red and pulses once, together with the clap.
  4. 4Ticks every 15 s, with long ticks at each minute. Phases of 60 s or less get 5 s ticks.
  5. 5Hub shows the digits and a short line (round or what’s next). In the Top and Bottom bands the digits sit beside the dial instead.

6 · Voice grammar Timer commands next to the existing “combo …” commands, all on one shared mic

SayDoesFires on
set 2 minutes countdown
countdown 90 seconds
set a 2 minute 30 timer		Quick countdown: one round of that length after the lead-in, starts right away. Saved settings are not changed.final
set 5 rounds of 3 minutesRuns that workout with rest and cues from settings, and starts it.final
set rest 30 seconds · set rounds 6
set round 2 minutes · set delay 5 seconds		Changes one saved setting (idle only). The confirmation line flashes the new value.final
preset muay thai · preset boxing · preset tabataLoads a built-in or saved preset (idle only).final
timer start / start timerStarts the current settings, or resumes if paused.interim
timer pause · timer resumePause and resume.interim
timer skipEnds the current phase now (lead-in, round or rest).interim
timer stop / timer resetStops and goes back to setup.interim
  • A bare “pause” / “stop” is ignored on purpose, because gym chatter would set it off. Controls need the word timer. Duration commands need countdown / timer / rounds / rest / delay. “set” is optional, since it’s often misheard as “said” or “sit”.
  • Durations: digits or words (“two”, “to”, “too”), plus “N minutes”, “N seconds”, “N minutes M (seconds)”, “a minute and a half”, “90 seconds” and “2:30”. The number mishearings reuse WORD_TO_NUM from the combo grammar.
  • Echo guard: results are ignored while our own TTS is speaking (+0.5 s). Spoken lines (“Round 2”, “Rest”, “Ten seconds”) never contain a trigger word either.
