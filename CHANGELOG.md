# Changelog

What changed for people using Glove Mode, newest first. Each version's bullets are its
"What's new" text in Google Play (en-US, 500 characters at most; `npm test` checks the newest),
so write them for testers. Version numbers and the release steps: [RELEASING.md](RELEASING.md).

## 1.0.0 — 2026-11-03

The first closed-testing builds, 2026-10-13 to 2026-11-03. All four were named 1.0.0; their build
numbers tell them apart.

- Build 5 (2026-11-03): "start timer" misheard as "stop timer" starts the timer; the voice log
  no longer marks a command that ran as ignored.
- Build 4 (2026-10-29): opt-in voice log in Settings; level bars and a Deadliest skull on combo
  cards and filter chips.
- Build 3 (2026-10-14): crash and voice error reports with a crash screen; the offline voice
  model download is offered once per app run.
- Build 2 (2026-10-13): first production build, on Expo SDK 57.
